┌─────────────────────────────────────────────────────────────────────────────────┐
│ CARACTERÍSTICAS DEL SCRIPT PRINCIPAL                                            │
└─────────────────────────────────────────────────────────────────────────────────┘

✓ SIFT Detection
  └─ Detección automática de características invariantes a escala

✓ Matching con Filtro de Lowe
  └─ Solo matches de alta calidad (ratio test: 0.70)

✓ Estimación de Pose Robusta
  └─ RANSAC para matriz esencial
  └─ Recuperación de R (rotación) y t (traslación)

✓ Validación de Ángulo
  └─ Evita pares con bajo cambio (ángulo < 12°)
  └─ Mejora robustez, reduce ruido

✓ Triangulación 3D
  └─ Genera nube de puntos desde pares válidos

✓ Acumulación Global
  └─ Integra puntos en sistema de coordenadas unificado
  └─ Trata la secuencia como flujo continuo

✓ Filtrado de Outliers
  └─ Elimina puntos infinitos o muy lejanos
  └─ Parámetros configurables

✓ Visualización 3D
  └─ Scatter plot coloreado por profundidad
  └─ Colormap viridis para mejor interpretación
  └─ Guardado en PNG de alta resolución (300 DPI)

✓ Logging Detallado
  └─ Información de cada par procesado
  └─ Estadísticas de matches
  └─ Avisos y errores claros

✓ Manejo Robusto de Errores
  └─ Try-catch en operaciones críticas
  └─ Mensajes descriptivos
  └─ Continúa si una carpeta falla
